System Architecture & Methodology

Analyst Desk: Institutional Equity Research Platform

Analyst Desk is an agentic multi-agent research workspace built on LangGraph and FinRobot. It bridges unstructured Large Language Model synthesis with deterministic SEC EDGAR XBRL ingestion, Python sandbox arithmetic verification, and automated 10-K risk factor diffs.

01

Deterministic XBRL Ingestion

Pulls official structured SEC EDGAR XBRL facts (Revenues, Operating Income, Net Income) mapped to unique immutable Fact IDs (FACT:MSFT:REV:FY2024).

02

Python Sandbox Arithmetic

All financial ratios (operating margins, YoY growth, basis point deltas) are computed inside a secure Python sandbox executing hard-coded verification checks prior to publishing.

03

10-K Item 1A Risk Diffs

Performs semantic and structural longitudinal diffing across successive annual 10-K filings to surface newly added, removed, or materially altered regulatory risks.
